Basic WebSocket Test

This WebSocket client runs in a browser. Two more clients run headless in Node JS. All clients share the same code and connect to CF DO WebSocket Server with Hibernate.

For this test, the server broadcasts whatever a client sends to all other clients and closes a client's connection having sent 4 messages to it. Before sending the second message, a client waits long enough for the server side to hibernateon the connection. A client can still send a message after the server closed its connection.
